นโยบายความเป็นส่วนตัว

Good Planner เป็นโครงงานของนักศึกษารายวิชา SF240 กลุ่มหมูบด ใช้เพื่อวางแผนงานส่วนตัวและหาเวลาว่างร่วมกันของกลุ่ม ปรับปรุงล่าสุด 13 พฤศจิกายน 2569

ข้อมูลที่เก็บ

  • ชื่อที่แสดงและอีเมล จากการสมัครสมาชิกหรือการเข้าสู่ระบบด้วย Google
  • งานส่วนตัว กลุ่ม ช่วงเวลาที่ไม่ว่าง งานกลุ่ม และนัดหมายที่คุณบันทึกเอง
  • รหัสผ่านถูกเก็บแบบเข้ารหัสทางเดียว ระบบไม่เห็นรหัสผ่านจริง

การใช้ข้อมูล

  • แสดงปฏิทินและคำนวณเวลาว่างร่วมของกลุ่ม สมาชิกคนอื่นเห็นเฉพาะช่วงที่คุณไม่ว่าง ไม่เห็นชื่องานส่วนตัว
  • ส่งอีเมลแจ้งเตือนงานและนัดหมาย ปิดได้ทุกเมื่อที่ปุ่ม "อีเมลเตือน" บนหน้าแผนส่วนตัว
  • ไม่ขาย ไม่ส่งต่อ และไม่ใช้ข้อมูลเพื่อโฆษณา

ข้อมูลจาก Google

การเข้าสู่ระบบด้วย Google ใช้เฉพาะชื่อและอีเมลที่ยืนยันแล้ว สิทธิ์ส่งอีเมล (gmail.send) ขอจากบัญชีผู้ดูแลระบบเพียงบัญชีเดียว เพื่อส่งอีเมลแจ้งเตือนออกจากบัญชีนั้น ระบบไม่อ่านอีเมลในกล่องจดหมายของใคร การใช้ข้อมูลจาก Google API เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

การลบข้อมูล

ติดต่อผู้ดูแลกลุ่มหมูบดเพื่อขอลบบัญชีและข้อมูลทั้งหมด ข้อมูลจะถูกลบภายใน 7 วัน
